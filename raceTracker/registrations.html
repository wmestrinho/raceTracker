How This Works

MotorsportReg REST API Entry lists via /rest/events/{id}/entries.json. Public events may work without a key; private events need MOTORSPORTREG_APIKEY set as a Worker secret.
RaceSelect HTML parse No public API — the Worker fetches the event page and parses the registration table. Works for any RaceSelect event URL.
Setup Add real event IDs Update event-schedule.json with the real MotorsportReg event UID (from the event URL) once Nuno confirms which rounds he's entering.
