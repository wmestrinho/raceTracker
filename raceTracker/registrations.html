NKA Pre-Tech Submission

Modeled on the NKA Technical/Safety Inspection Form (Rulebook §10.4.12) — every driver fills this out and signs before entering the grid for qualifying. Event officials may still spot-check on the day.

Driver sign-off
DriverKartClassEventSubmittedStatus

Checklist items follow the NKA Rulebook: §10.4.6 (helmet, neck collar, chest protector), §10.4.10 (weight/ballast) and §10.4.11 (Safety Tech Standards — nylock-nut/safety-wired connections). NKA's own Pre-Tech form is only available by request from NKA directly; confirm against your sanctioned series' current rulebook — this is not a substitute for official tech.

How This Works

MotorsportReg REST API Entry lists via /rest/events/{id}/entrylist.json. {id} is MotorsportReg's internal event ID — not the number in the public event URL — and isn't visible on the public event page; confirm it with MotorsportReg or the event organizer. Private events need MOTORSPORTREG_APIKEY set as a Worker secret.
RaceSelect HTML parse No public API — the Worker fetches the event's own /EventEntries page (not the series season-index page) and parses its entry rows. Verified working against a real live event.
Setup Add real event IDs Update event-schedule.json with the real MotorsportReg internal event ID or the RaceSelect /EventEntries URL once the team confirms its rounds.
